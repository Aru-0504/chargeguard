# ChargeGuard - AI-Powered Fraud Detection & Chargeback Prevention

ChargeGuard is an agentic fraud prevention and chargeback automation platform.

## Project Structure

- `ml/`: Machine learning data, models, and notebooks.
- `backend/`: FastAPI application.
- `agent/`: LangGraph agent for chargeback evidence generation.
- `frontend/`: Next.js web interface (to be scaffolded).
- `docs/`: Architecture diagrams and documentation.
