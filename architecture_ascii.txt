DATA FLOWS
==========

1. TRANSACTION SCORING
   Dashboard → API → LightGBM Model → SHAP Explainer → Database

2. EVIDENCE GENERATION
   Dashboard → API → LangGraph Agent → OpenAI GPT-4 → Database

3. MODEL MONITORING
   Dashboard → API → SHAP → Global Importance → Dashboard

4. MODEL RETRAINING
   Retrain Script → New Model → Model Version → Database → Promotion


KEY TECHNOLOGIES
================

Frontend:  Next.js, TypeScript, React, TailwindCSS
Backend:   FastAPI, Python, SQLAlchemy
ML:        LightGBM, SHAP, DiCE, LangGraph
Database:  PostgreSQL (with SQLite fallback)
External:  OpenAI GPT-4
